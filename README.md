# 心臓のアトリエ

個人の趣味として、人間の心臓を回して眺め、構造を楽しむ3Dモデルを作るプロジェクト。
最終成果物は単一のHTML。設計、実装、検証はChatGPTとClaudeが交代して担当する。

## 開き方

`index.html`をダウンロードしてWebGL対応ブラウザーで開く。コードとライブラリは内蔵しており、モデル表示にネット接続は不要。
iOSのファイルプレビューでの動作は未確認。プレビューアプリではなくブラウザーでの表示を対象とする。
ドラッグ／タッチで回転、スクロール／ピンチで拡大縮小。部位ボタンまたはモデルのクリックで選択。

## 現在の版と範囲

v0.1は外観と操作の試作。心房、心室、主要血管をコードで作った概形として表示する。
形状、重なり、血管接続、比率の解剖学的精度は未検証。中空の心腔を持たない。
内腔、弁、冠動脈、血流、拍動は未実装。医療用途ではない。

## 進め方

1. 外観試作：回転と拡大縮小、主要部位の選択。
2. 最初の完成版：資料との形状照合、外観の改善、部位説明と操作の調整。
3. 内部観察：内腔と弁を表せるモデル構造を検討してから実装。
4. 動き：血流方向と説明用の拍動を追加。

まずPCで確認し、スマートフォンでも操作しやすくする。
コード生成による概形に限界があれば、既存モデルの利用条件を確認して採用を検討する。
見栄えの良さと、主要部位の位置とつながりを説明できることを目標にする。

## AI向け開発手順

`npm ci` → `npm run build` → `npm test`。
テスト用Chromiumがなければ `npx playwright install chromium`。
ソースは `src/main.js`（形状、操作）、`src/template.html`（画面）、生成物は `index.html`。
Three.jsをesbuildで埋め込む。ユーザーにビルドを要求しない。ソースと生成物を同じコミットに含める。

## 設計判断

- 編集用ソースを分割し、配布物はHTML一つにまとめる。
- 外部CDN、外部モデル、外部フォントに実行時依存しない。
- 部位は安定したIDで管理し、画面と3D選択を同期する。
- 自動回転は初期状態で停止し、操作はボタンでも行える。
- 外観試作の形状を将来の内部モデルとして使えるとは仮定しない。

## 検証状況（初回実装）

ビルド成功。PlaywrightでPC幅とスマートフォン幅のオフライン起動、部位選択、表示操作を検証するテストを用意した。
実行環境のブラウザー起動制約（socket Operation not permitted）により、テスト本体と画面の目視確認は未実施。
ブラウザーを起動できる環境で確認してから、外観試作の完成を判定する。
システムのChromiumを利用する場合は `CHROMIUM_PATH=/path/to/chromium npm test`。
次の作業は表示と操作の検証、その後に資料との形状照合と外観改善。
