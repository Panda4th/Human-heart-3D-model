### 断面の位置ごとの照合（2026-11-07）

スライダーの各位置で、断面がどの部位を通るかを調べた。
座標は、生成データの軸（+xが身体の左、+yが上、+zが前）と、`createAnatomy`の中心合わせ（4つの心腔の外接箱の中心）に従って計算した。
スライダー値vの断面は、画面の単位でz = −vにあり、心臓の中心から前へ−v×約30mm。スライダーは−1.8〜1.8で、4つの心腔の前後の最外端（約±55mm、±1.807）に近い位置まで切れる（以前は−1.5〜1.5で、前後それぞれ約9mmが切れなかった）。下の表は−1.5〜1.5の位置で測った値。両端の−1.8と1.8は、下の「断面スライダー両端の追試」で扱う。

方法は2つ。
1. 各部位の三角形が断面と交わるかを数え、交わる部位と範囲を出した（心臓の中心からの距離は前が＋、mm）。表はこの数値による。
2. 同じ11か所を前面から撮り、目視した（クラウドのChromium）。各位置で、表の弁・心室・心房に当たる形が写っていることは確かめた。右心房の前部のような細部は、部位名と1つずつ突き合わせていない。

| スライダー | 中心から | 切れる主な部位（数値） |
|---|---|---|
| −1.5 | 前45mm | 右心室の壁と内腔、乳頭筋、冠動脈。左心室はごく端だけ |
| −1.2 | 前36 | 上に加え、右心房の前部、肺動脈と肺動脈弁、左心室の前壁 |
| −0.9 | 前27 | 三尖弁（腱索とみられる糸を含む）、肺動脈弁、右心室・右心房・左心室 |
| −0.6（初期値） | 前18 | 三尖弁、肺動脈弁、僧帽弁の端、左心房は先端だけ（2面。左心耳かは未確認） |
| −0.3 | 前9 | 大動脈と大動脈弁、僧帽弁、三尖弁、肺動脈弁が同時に切れる。左心房の前端 |
| 0 | 0 | 大動脈弁、僧帽弁、三尖弁、左心房、大静脈、右心室の後ろ寄り |
| 0.3 | 後9 | 右心室はほぼ終わる。三尖弁・肺動脈弁は切れない |
| 0.6 | 後18 | 右心室なし。左心室、左右の心房、僧帽弁、肺静脈 |
| 0.9 | 後27 | 左心室、左右の心房、僧帽弁の後ろ寄り、肺静脈 |
| 1.2 | 後36 | 左心房、左心室の後端、僧帽弁の端、肺静脈 |
| 1.5 | 後45 | 左心房、肺静脈、大動脈、肺動脈だけ。心室はない |

各部位の前後の中央値（前が＋）は、右心室+26mm、右心房−6、左心室−6、左心房−31。弁は肺動脈弁+20、三尖弁+11、大動脈弁−1、僧帽弁−18。
僧帽弁と三尖弁は、腱索とみられる糸の部分を含むため、前後の幅が広い（僧帽弁は約56mm）。

OpenStax 19.1の文章と矛盾しなかった点：
- 右側が前へ、左側が後ろへ寄る。右心室は前（中央値+26mm、0.6で消える）、左心房は後ろ（−31mm）にある。左心室は1.2、左心房は1.5まで残る。
- 左心室の壁は右心室より厚い。−0.6の画面で、左心室の壁の切り口が右心室より厚いことを目視した。
- 上大静脈は右心房の上・後ろに入る。大静脈の前後の範囲（−18〜+5mm）は、右心房の範囲（−36〜+40mm）のほぼ後ろ半分にある（上・下大静脈を合わせた値）。

資料では確かめていない点：
- 4つの弁の前後の並び（肺動脈弁が最も前、僧帽弁が最も後ろ）は、画面と数値では確かめたが、OpenStaxの文章には記述がなく、資料との照合は未了。
- OpenStax 19.1には「房室中隔のやや上の横断面で4つの弁が同じ平面に見える」という記述がある（2026-11-07に本文で確認）。弁尖の頂点の重心4つを最小二乗で平面に当てはめると、各点は平面から−3.6（僧帽弁）、−0.1（三尖弁）、＋8.6（大動脈弁）、−5.0mm（肺動脈弁）にあった。弁の大きさ（重心から最も遠い頂点まで16〜37mm）に比べれば小さい。ただし平面は鉛直から62°傾いていて（法線 x −0.63、y 0.46、z −0.62。+xが身体の左、+yが上、+zが前）、重心の上下の散らばりは39mmある。水平な横断面で4つの弁が同時に切れるかは、この形状では確かめていない。僧帽弁と三尖弁の重心は腱索とみられる糸を含むため弁輪の位置とは限らない。資料の図との比較は未了。
- 各位置の画面が、実際の心臓の同じ深さの断面と一致するかは、断面画像の資料と比べていない。

大静脈などの血管は、薄い殻として表示し、切り口の面は作らない（v0.4.1。v0.4では0〜0.3で管の内側が切り口の色に塗られていた）。


#### 断面スライダー両端の追試（2026-11-09、#17）

`main` の `d6e525f` の静止形状を、刺激伝導系と血流の重ね表示をオフにして確認した。切断面は、4心腔の外接箱の中心から前後に54.55 mm。スライダーの端は前後とも、心臓の壁の最外端から約0.20 mm内側にある。

| スライダー | 切断面が横切る部位（交差する三角形の数） |
| --- | --- |
| −1.8（前端） | 右心室壁 13、冠動脈 26 |
| ＋1.8（後端） | 左心房壁 11、大動脈 122、肺動脈 66、肺静脈 25 |

`node scripts/inspect-section-endpoints.mjs` で再計測できる。ビューアーと同じ `createAnatomy` と縮尺で、表示部品15個の元の三角形を取り出す。頂点が切断面の両側にある面を数え、面への接触だけの場合と区別する。両端とも接触だけの面はなかった。比較用の−1.5と＋1.5で交差する部位は、2026-11-07の計測表と一致した。三角形の数はメッシュの分割の細かさに依存する。血管にも交差はあるが、ビューアーが塗りつぶす切り口は心臓の壁に限られる。

同じ配布HTMLをChromiumとLinux版WebKitでオフラインで開き、断面モードの初期視点から、スライダーをHome／Endキーで移動して撮影した。前端では心臓の外形と冠動脈の大半が残り、右心室前面に小さな切り口が見える。後端では、左心房の小さな切り口と血管の一部だけが残る。画面上の判定はこの撮影条件に限る。iPhone実機での追試は行っていない。
