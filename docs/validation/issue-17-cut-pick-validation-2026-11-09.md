# Issue #17 切り口の心腔名が異なる11点の追試（2026-11-09）

対象は main `d6e525f`。既存の単体テストと同じ3断面×3視点、同じ3方向の基準で225点を再計測した。配布HTMLのGit blobは `01e9bc86a573c0e5c57c24ec01610e1536e73c30`。可視化の検証コードは [`c41b3e7`](https://github.com/Panda4th/Human-heart-3D-model/commit/c41b3e7fdf797cdf131a55cde19fcc367dd5ae55)。

## 原因の切り分け

225点中11点の不一致を再現。比較基準は左心室7点、右心室4点で、現行はすべて左心房。クリックの光線は11点とも切り口の奥で左心房の壁面だけに当たり、左心房の面の表裏の差は各点で +1 だった。切り口の明るい領域を描く計算にも、視線方向の面の表裏の差を使っている。3方向で心腔を推定する基準は、視点から見える切り口の分類と異なる結果を返す。

既報の457グループの重複面を頂点の0.01mm単位で特定した。この225点ではクリック方向にも、基準を求める3方向にも重複面への交差がなく、仮に除外しても判定は同じだった。前回の重複箇所を狙った検証で得た43点とは、対象点が異なる。

## 判断

11点への重複面の寄与は確認されず、原因調査を終了する。どの候補も全点を解消せず、現行の部位名は切り口の強調と対応する。11点では他の心腔の表裏の差がすべて0で、部位名の決め方だけを置き換えると、選んだ心腔の強調領域からクリック点が外れる。現行の判定を維持する。3方向の比較基準との不一致11点は既知の制約として残す。

`node scripts/inspect-cut-picks.mjs` で225点の数値を再現できる。[11点の計測JSON](issue-17-cut-pick-measurements-2026-11-09.json)と[クリック後の画面6構図](issue-17-cut-pick-evidence-2026-11-09.jpg)を参照。実機Safariでは今回の11点を確認していない。
