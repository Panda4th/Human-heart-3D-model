## 自己レビューと対応（2026-11-07）

初期版をコード、形状生成、操作判定、配布物、検証の観点から再点検した。
「免責を付ければ十分」とせず、誤認につながる形状と未検証項目を残課題として扱う。

| 重要度 | 問題 | 対応と残る制約 |
|---|---|---|
| 高 | 球と管の重なりを解剖模型として扱うには精度が不足 | v0.3でBodyParts3Dの形状に置き換えて解消。心房・心室の境界と刺激伝導系の位置は推定のまま |
| 高 | 固定距離では縦長画面の横画角が足りず見切れ得る | モデル境界と縦横画角で距離を算出。5種類の画面比率、3方向の全頂点を計算で検証 |
| 中 | ピンチ、キャンセル、往復ドラッグをクリックと誤認し得る | ポインターID、移動履歴、複数指、キャンセルを追跡する判定へ変更 |
| 中 | 静止時にも連続描画して電池を消費する | 必要時のみ描画し、回転時だけフレームを継続。タブ非表示と操作開始で停止 |
| 中 | キーボードで任意方向に回転できない | 矢印キー操作と前面・背面・側面ボタンを追加 |
| 中 | WebGL喪失時に説明がなく操作できるように見える | 画面に再読み込み案内を表示し操作ボタンを無効化 |
| 中 | HTML単体ではThree.jsの完全なMITライセンスが付属しない | ライセンス全文をHTMLへ埋め込み、画面からも読めるように変更 |
| 高 | 初回の表示テストが実行されていない | ローカルはsocket制限で起動不可。GitHub Actionsで5件のブラウザーテストが成功し、PCとスマートフォン幅の保存画像を目視確認 |
